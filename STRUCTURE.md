## File Descriptions

### Source Files

#### App Entry Point
- **main.tsx** - React app initialization, mounts to DOM
- **App.tsx** - Main application component with 6-page routing system

#### Pages (6 full-featured pages)
- **Dashboard.tsx** - Financial overview with health score, fund progress, alerts
- **Income.tsx** - Track income from 5 sources (Salary, Bonus, Freelance, Gift, Other)
- **Expenses.tsx** - Categorize expenses (11 categories), track spending
- **Goals.tsx** - Manage 4 savings goals with progress visualization and forecasting
- **Reports.tsx** - Analytics with 4 chart types, export functionality
- **FinancialCoach.tsx** - AI recommendations, health insights, scenario planning

#### Components
- **Header.tsx** - Fixed top navigation with dark mode toggle
- **BottomNav.tsx** - Fixed bottom mobile navigation (6 page tabs)
- **Card.tsx** - Reusable container component (dark theme)
- **ProgressBar.tsx** - Linear progress indicator (0-100%)
- **ProgressRing.tsx** - Circular SVG-based progress indicator
- **Badge.tsx** - Status badges (Excellent, Good, Average, Poor, Critical)

#### State Management
- **AppContext.tsx** - Global state provider (Context API)
  - Manages all app state
  - Provides 14+ action functions
  - Auto-saves to localStorage
- **useLocalStorage.ts** - Custom hook for localStorage integration
- **storage.ts** - LocalStorage service with export/import

#### Business Logic
- **finance.ts** - 20+ financial calculation functions
  - computeHealthScore() - Calculate 0-100 health score
  - generateRecommendations() - AI recommendations
  - simulateExpense() - "Can I afford this?" testing
  - forecastCashFlow() - 6-month cash flow prediction
  - forecastGoalCompletion() - Goal completion date calculation
  - calculateNetWorth() - Total savings calculation
  - Plus 10+ helper functions

- **formatters.ts** - Formatting utilities
  - formatCurrency() - Indian rupee formatting (₹)
  - formatDate() - Date formatting
  - monthLabel() - Month name generation

- **types/index.ts** - TypeScript type definitions
  - Transaction types (Income, Expense)
  - Goal types (Emergency, Sibling, PC, Future)
  - State types (AppState, Settings)
  - Analytics types (Health, Recommendation, Report)

- **index.css** - Global styles and Tailwind directives

## File Organization Principles

1. **Feature-based Structure** - Grouped by feature/page
2. **Separation of Concerns** - Components, utilities, services separated
3. **Reusable Components** - UI components in `components/ui/`
4. **Centralized Types** - All TypeScript types in `types/index.ts`
5. **Business Logic** - Financial functions in `utils/finance.ts`
6. **State Management** - Context and storage in dedicated folders
